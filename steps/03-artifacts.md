# Step 03: Artifacts の概念理解

## 目標

Claude の Artifacts 機能の概念と、Claude Code との関係を理解する。

## Artifacts とは

Artifacts は、Claude が生成したコンテンツを独立したパネルに表示する機能です。Claude アプリ（Web / デスクトップ）で利用できます。

### Artifacts の種類

| 種類 | 説明 | 例 |
|------|------|----|
| コード | 実行可能なコード | React コンポーネント、Python スクリプト |
| ドキュメント | Markdown テキスト | レポート、仕様書 |
| Web ページ | HTML/CSS/JS | インタラクティブな UI プレビュー |
| SVG | ベクター画像 | 図表、アイコン |
| Mermaid | ダイアグラム | フローチャート、ER図 |

### Artifacts の特徴

- 会話の右側パネルに表示される
- コードはその場でプレビュー・実行できる
- 会話の中で繰り返し編集・更新できる
- 共有リンクを生成して他の人に見せられる

## Claude Code と Artifacts の関係

| | Claude アプリ (Artifacts) | Claude Code |
|---|--------------------------|-------------|
| 出力先 | ブラウザ上の Artifact パネル | ローカルのファイルシステム |
| 実行 | ブラウザ内のサンドボックス | ローカルのターミナル |
| 用途 | プロトタイプ、プレビュー | 本番コードの開発 |
| 保存 | Claude の会話内 | ローカルのファイル |

### 使い分け

- **ちょっと試したい**: Artifacts（ブラウザ上ですぐプレビュー）
- **本番で使うコード**: Claude Code（ローカルに直接ファイル生成）
- **チーム共有**: Artifacts（共有リンク生成）
