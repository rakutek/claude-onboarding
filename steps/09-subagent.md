# Step 09: Subagent（Task tool）の理解

## 目標

Claude Code の Subagent（サブエージェント）の仕組みと活用方法を理解する。

## Subagent とは

Subagent は、Claude Code がタスクの一部を別の Claude インスタンスに委任する仕組みです。メインの Claude が「監督」、Subagent が「担当者」として並行作業します。

```
メイン Claude（監督）
├── Subagent A: 「このファイルのテストを書いて」
├── Subagent B: 「この関数のドキュメントを調べて」
└── Subagent C: 「セキュリティの問題をチェックして」
       ↓ それぞれ独立して作業
    結果をメイン Claude に報告
```

## なぜ Subagent が必要？

### 1. 並行処理

複数のタスクを同時に処理できます。例えば、3つのファイルを同時に分析するといった作業が可能です。

### 2. コンテキストの分離

メインの会話が長くなると、コンテキストウィンドウ（Claude が一度に扱える情報量）が圧迫されます。Subagent に作業を委任すると、メインのコンテキストを節約できます。

### 3. 専門特化

各 Subagent にそれぞれ異なる指示を与えて、専門的な分析をさせることができます。

## Subagent の動作

Claude Code では、Agent ツール（内部的には Task tool）として実装されています。

```
ユーザー: 「このプロジェクトのセキュリティとパフォーマンスをレビューして」
    ↓
メイン Claude:
  → Subagent 1 を起動:「セキュリティ観点でレビュー」
  → Subagent 2 を起動:「パフォーマンス観点でレビュー」
    ↓
各 Subagent が独立して分析
    ↓
メイン Claude: 結果を統合してユーザーに報告
```

### Subagent の特徴

| 特徴 | 説明 |
|------|------|
| 独立したコンテキスト | メインとは別のコンテキストで動作 |
| 並行実行 | 複数の Subagent を同時に起動可能 |
| ツール利用 | ファイル読み書き、検索など一部のツールを使える |
| 結果報告 | 完了後、メインに結果を返す |
