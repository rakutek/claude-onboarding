# Step 04: 言語設定（/config）

## 目標

Claude Code の応答言語を日本語に設定し、設定の仕組みを理解する。

## なぜ言語設定が必要？

Claude Code はデフォルトで英語で応答します。日本語で応答させるには、設定を変更する必要があります。

## 設定方法

### 方法 1: `/config` コマンド（推奨）

Claude Code の会話内で以下を入力します：

```
/config
```

設定画面が表示されるので、`language` の項目を選択し、「日本語」に設定します。


## 設定のスコープ

Claude Code の設定には4つのスコープがあります：

| スコープ | ファイル | 適用範囲 |
|---------|--------|---------|
| **Managed** | システムレベル（IT管理者が配置） | 組織全体（上書き不可） |
| **ユーザー** | `~/.claude/settings.json` | すべてのプロジェクト |
| **プロジェクト** | `プロジェクト/.claude/settings.json` | そのプロジェクト（Git で共有） |
| **ローカル** | `プロジェクト/.claude/settings.local.json` | そのプロジェクト（個人用、Git 管理外） |

優先順位は Managed > ローカル > プロジェクト > ユーザー です。

言語設定はユーザースコープ（`~/.claude/settings.json`）に保存されるため、一度設定すればすべてのプロジェクトで有効です。

## その他の便利な設定

| 設定 | 説明 |
|------|------|
| `language` | 応答の言語 |
| `permissions.defaultMode` | デフォルトの権限モード（`default` / `plan` / `acceptEdits` 等） |
| `autoMemoryEnabled` | 自動メモリ機能の有効/無効 |

## やってみよう

1. `claude` を起動する
2. `/config` と入力する
3. 言語設定を「日本語」に変更する
4. 何か質問して、日本語で応答されることを確認する
5. `/exit` で終了し、再度 `claude` を起動して設定が保持されていることを確認する
