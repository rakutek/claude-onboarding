# Step 11: SoTA モデルの高速化（Fast Mode）

## 目標

Claude Code の Fast Mode を理解し、効率的なモデル使い分けを学ぶ。

## Fast Mode とは

Fast Mode は、Claude Code の応答速度を優先するモードです。同じ Opus モデルをより高速な出力で利用できます。

```
通常モード: Opus（高品質・じっくり）
Fast モード: Opus（同じモデル・高速出力）
```

> **重要**: Fast Mode は別のモデルに切り替わるのではなく、同じ Opus モデルの高速バージョンです。

## 切り替え方法

### Claude Code 内で切り替え

```
/fast
```

これだけで Fast Mode に切り替わります。もう一度 `/fast` を入力すると通常モードに戻ります。

## いつ Fast Mode を使うか

| シーン | モード | 理由 |
|--------|--------|------|
| 複雑な設計判断 | 通常 | じっくり思考が必要 |
| コード生成 | Fast | 速度重視で量をこなす |
| バグ修正 | 通常 | 正確な分析が必要 |
| ファイル検索・要約 | Fast | シンプルなタスク |
| リファクタリング | 通常 | 全体を見通す必要 |

## レートリミットとの関係

Fast Mode を活用することで、レートリミット内でより多くのタスクをこなせます。

```
例: 1日のトークン予算が 100 の場合

通常モード: 10回の高品質応答
Fast モード: 同じ品質で高速に応答（同じトークン消費だが待ち時間が短縮）
```

### レートリミット節約のコツ

1. **シンプルなタスクは Fast Mode**: ファイル検索、フォーマット修正など
2. **複雑なタスクは通常モード**: 設計判断、複雑なデバッグなど
3. **Subagent を活用**: 並行処理でトータルの待ち時間を削減

## やってみよう

1. Claude Code を起動する
2. 通常モードで質問する：
   ```
   CLAUDE.md の内容を要約して
   ```
3. `/fast` で Fast Mode に切り替える
4. 同じ質問をして、速度の違いを体感する：
   ```
   progress.json の内容を要約して
   ```
5. `/fast` でもう一度切り替えて通常モードに戻す

- [ ] どんなタスクで Fast Mode を使うべきか判断できる
