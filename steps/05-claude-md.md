# Step 05: CLAUDE.md の理解

## 目標

CLAUDE.md の役割と仕組みを理解する。このチュートリアル自体が CLAUDE.md の実例であることを体験する。

## CLAUDE.md とは

CLAUDE.md は、Claude Code が起動時に自動的に読み込む指示ファイルです。プロジェクトのルールやコーディング規約、Claude への指示をここに書いておくと、毎回の会話で自動的に反映されます。

```
プロジェクトルート/
├── CLAUDE.md          ← Claude が自動で読み込む
├── src/
├── package.json
└── ...
```

## 何を書くのか

| カテゴリ | 例 |
|---------|-----|
| プロジェクト概要 | 「これは○○のためのアプリケーションです」 |
| コーディング規約 | 「関数名はキャメルケースで書く」 |
| 応答のルール | 「常に日本語で応答する」「コード変更時はテストも更新する」 |
| 使うツール | 「テストは vitest を使う」「パッケージマネージャは pnpm」 |
| 禁止事項 | 「`.env` ファイルは変更しない」 |

## CLAUDE.md の配置場所と優先順位

| 場所 | 読み込み | 用途 |
|------|---------|------|
| `~/CLAUDE.md` | 全プロジェクト共通 | 個人の共通ルール |
| `プロジェクト/CLAUDE.md` | そのプロジェクト | プロジェクト固有のルール |
| `プロジェクト/サブディレクトリ/CLAUDE.md` | そのディレクトリ以下 | サブモジュール固有のルール |

複数の CLAUDE.md が存在する場合、すべてが読み込まれ、より具体的なもの（サブディレクトリ）が優先されます。

## このチュートリアルの CLAUDE.md

今あなたが体験しているこのチュートリアル自体が、CLAUDE.md の実例です。

このプロジェクトの `CLAUDE.md` には以下が書かれています：
- Claude の役割（オンボーディングガイド）
- ステップ一覧
- `/next` の進行フロー
- 利用可能なスキル

Claude Code を起動した瞬間にこの指示が読み込まれ、ガイドとして振る舞えるようになっています。

## やってみよう

1. このプロジェクトの `CLAUDE.md` を読んでみましょう

   Claude Code 内で：
   ```
   CLAUDE.md を読んで、内容を要約して
   ```

2. CLAUDE.md にルールを1行追加してみましょう
   - 例：「回答の最後に励ましの一言を添える」
   - 追加後、新しいセッションを開始して反映されるか確認する
