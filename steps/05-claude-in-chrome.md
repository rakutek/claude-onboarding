# Step 05: Claude in Chrome の導入と活用

## 目標

Claude in Chrome（Chrome 拡張機能）をインストールし、ブラウザ内で Claude にタスクを委任できる状態にする。Claude Code との連携も理解する。

## Claude in Chrome とは

Claude in Chrome は、Anthropic 公式の Chrome 拡張機能です。ブラウザ上で Claude がウェブサイトを読み取り、クリックし、ナビゲートして、あなたのタスクを代行します。

```
Chrome ブラウザ
├── Claude サイドバー  ← 自然言語で指示
│     ↓
├── ウェブサイト操作   ← クリック、入力、ナビゲーション
├── 複数タブ管理       ← タブグループで一括操作
├── ワークフロー記録   ← 繰り返しタスクの自動化
└── Claude Code 連携   ← ターミナルで構築 → ブラウザで検証
```

### Claude Code との違い

| | Claude Code | Claude in Chrome |
|---|------------|-----------------|
| 動作場所 | ターミナル（CLI） | Chrome ブラウザ |
| 主な用途 | コード生成・編集・実行 | ウェブサイト操作・情報収集 |
| 操作対象 | ファイル・コマンド | ウェブページ・フォーム |
| 連携 | MCP でブラウザ接続 | Claude Code と双方向連携 |

### できること

| 機能 | 例 |
|------|-----|
| ウェブ操作 | フォーム入力、ボタンクリック、ページ遷移 |
| 情報収集 | ウェブページの要約、データ抽出 |
| メール・カレンダー | Gmail の下書き作成、Google Calendar の予定追加 |
| 開発支援 | GitHub の PR 確認、ブラウザコンソールのエラー確認 |
| 複数タブ操作 | 複数ページ間での情報統合・操作 |
| ワークフロー自動化 | 繰り返し作業の記録と再実行 |

## 対応プラン

Claude in Chrome は **有料プランのユーザー** が利用できます。

| プラン | 利用可否 | 選択可能モデル |
|--------|---------|--------------|
| Free | 利用不可 | - |

## インストール手順

### 1. Chrome Web Store からインストール

1. Google Chrome を開く（他の Chromium ブラウザは非対応）
2. [Chrome Web Store の Claude ページ](https://chromewebstore.google.com/publisher/anthropic/u308d63ea0533efcf7ba778ad42da7390) にアクセス
3. **「Chrome に追加」** をクリック
4. 権限の確認ダイアログで **「拡張機能を追加」** をクリック

### 2. 拡張機能をピン留め

1. Chrome 右上のパズルアイコン 🧩 をクリック
2. Claude の横にあるピンアイコンをクリック
3. ツールバーに Claude アイコンが常時表示される

### 3. サインイン

1. ツールバーの Claude アイコンをクリック
2. サイドバーが開く
3. Claude アカウントでサインイン（有料プランが必要）

### 4. 権限の設定

初めてウェブサイトで Claude を使う際に、サイトごとの権限を確認されます。

- **許可**: そのサイトで Claude が操作可能になる
- **拒否**: そのサイトでは Claude が操作できない

## 基本的な使い方

### サイドバーから指示する

Claude アイコンをクリックしてサイドバーを開き、自然言語で指示します。

```
例：
「このページの内容を要約して」
「このフォームに以下の情報を入力して：名前は山田太郎、メールは...」
「GitHub のこの PR のレビューコメントをまとめて」
```

### 複数タブの操作

タブを Claude のタブグループにドラッグすると、複数タブを一括で操作できます。

```
例：
「グループ内の全タブから価格情報を抽出して比較表を作って」
「3つのタブの記事を読んで共通点をまとめて」
```

### ワークフローの記録

繰り返し行うタスクを記録して、ショートカットとして保存できます。

1. サイドバーで「ワークフローを記録」を開始
2. 手動で一連の操作を実行
3. Claude が操作パターンを学習
4. 次回から「ショートカット」で再実行

## Claude Code との連携

Claude in Chrome と Claude Code は連携して使うことで、開発ワークフローを強化できます。

```
Claude Code（ターミナル）          Claude in Chrome（ブラウザ）
       │                                    │
       │  1. コードを書く・修正する           │
       │──────────────────────────────────→  │
       │                    2. ブラウザで動作確認  │
       │  ←──────────────────────────────────│
       │  3. エラーをフィードバック            │
       │  4. コードを修正                     │
       └────────────────────────────────────┘
```

## セキュリティに関する注意

Claude in Chrome はベータ機能です。以下の点に注意してください：

| 推奨 | 非推奨 |
|------|--------|
| 慣れ親しんだサイトから始める | 金融取引に使う |
| サイトごとに権限を管理する | パスワード入力を任せる |
| 操作内容を確認してから承認する | 機密データの操作を任せる |
| 信頼できるワークフローで使う | 知らないサイトで全権限を許可する |
