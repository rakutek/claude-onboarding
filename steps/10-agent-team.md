# Step 10: Agent Team の理解

## 目標

Agent Team（マルチエージェント構成）の概念と、Subagent との違いを理解する。

## Agent Team とは

Agent Team は、複数の専門エージェントがそれぞれの役割で協力してタスクを遂行する構成です。Subagent が「一時的な委任」なのに対し、Agent Team は「役割分担された組織」です。

```
┌─────────────────────────────────────┐
│           Agent Team                │
│                                     │
│  ┌───────────┐  ┌───────────┐      │
│  │ リサーチ    │  │ レビュー    │      │
│  │ エージェント │  │ エージェント │      │
│  └───────────┘  └───────────┘      │
│  ┌───────────┐  ┌───────────┐      │
│  │ 実装       │  │ テスト      │      │
│  │ エージェント │  │ エージェント │      │
│  └───────────┘  └───────────┘      │
│                                     │
│  オーケストレーター（統括）           │
└─────────────────────────────────────┘
```

## Subagent との違い

| | Subagent | Agent Team |
|---|---------|------------|
| 関係 | メイン → 子 | 対等なチーム |
| 役割 | 一時的な委任 | 専門的な役割分担 |
| スコープ | 単一タスク | プロジェクト全体 |
| 実行 | Claude Code 内 | 複数の Claude Code セッション |

## Agent Team の実現方法

### 1. Claude Code のマルチセッション

複数のターミナルでそれぞれ Claude Code を起動し、異なる役割を与えます。

```bash
# ターミナル1: 実装担当
cd my-project && claude
> 新機能を実装して

# ターミナル2: テスト担当
cd my-project && claude
> テストを書いて

# ターミナル3: レビュー担当
cd my-project && claude
> コードレビューして
```

### 2. スキルベースの役割定義

SKILL.md にエージェントの役割を定義し、専門的な振る舞いをさせます。

### 3. Worktree による並行開発

Git worktree を使えば、同じリポジトリの異なるブランチで同時に作業できます。

```bash
# メインで機能A、worktree で機能B を同時開発
git worktree add ../feature-b feature-b
```

## 活用例

| シナリオ | チーム構成 |
|---------|-----------|
| 大規模リファクタリング | 分析エージェント + 実装エージェント + テストエージェント |
| コードレビュー | セキュリティ専門 + パフォーマンス専門 + 設計専門 |
| 新機能開発 | リサーチ + 実装 + ドキュメント |
