# Step 12: OpenClaw 紹介

## 目標

OpenClaw の概要を知り、Claude Code の拡張エコシステムについて理解する。

## OpenClaw とは

OpenClaw は、Claude Code のスキルやプラグインを共有・発見できるコミュニティプラットフォームです。誰でもスキルを公開でき、他の人が作ったスキルを利用できます。

```
開発者 A: スキルを作成 → OpenClaw に公開
        ↓
開発者 B: OpenClaw で検索 → インストールして利用
```

## 何が共有されているか

| カテゴリ | 例 |
|---------|-----|
| 開発ツール | テスト自動化、コードレビュー、リファクタリング |
| ドキュメント | API ドキュメント生成、README 自動更新 |
| DevOps | CI/CD 設定、デプロイ自動化 |
| デザイン | Figma 連携、UI コンポーネント生成 |

## セキュリティに関する注意

### 外部スキルの利用時に確認すべきこと

| チェック項目 | 理由 |
|-------------|------|
| スキルの作成者 | 信頼できるソースか確認 |
| SKILL.md の内容 | どんなコマンドが実行されるか確認 |
| 権限の要求 | 不必要に広い権限を要求していないか |
| ファイルアクセス | 意図しないファイルにアクセスしていないか |

### 安全な利用のためのルール

1. **インストール前に SKILL.md を読む**: どんな操作が行われるか確認する
2. **権限は最小限に**: 不要な権限を許可しない
3. **社内プロジェクトでは慎重に**: 機密コードにアクセスするスキルは特に注意
4. **定期的に見直す**: 不要になったスキルは削除する

## Claude Code のエコシステム

OpenClaw は Claude Code のエコシステムの一部です：

```
Claude Code
├── 組み込み機能（Read, Edit, Bash, etc.）
├── MCP サーバー（外部ツール接続）
├── Skills（カスタムワークフロー）
│   ├── 自作スキル
│   └── OpenClaw からのスキル ← ここ
└── Plugins（プラグイン）
```
