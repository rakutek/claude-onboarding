# Step 01: Claude Desktop のインストールと料金プランの理解

## 目標

Claude Desktop をインストールし、料金プランごとの違いと Claude Code の利用条件を理解する。

## Claude Desktop のインストール

Claude Desktop は、Anthropic が提供する公式デスクトップアプリです。ブラウザを開かずに Claude を使えます。

### インストール手順

1. [Claude Desktop ダウンロードページ](https://claude.ai/download) にアクセスする
2. お使いの OS に合ったインストーラーをダウンロードする
3. アプリを起動し、会社で契約したClaude アカウントでサインインする

> **注意**: アカウントをまだ持っていない場合は、[claude.ai](https://claude.ai) でアカウントを作成してください。

## プラン比較

| 項目 | Free | Pro ($20/月) | Max 5x ($100/月) | Max 20x ($200/月) | Team Standard ($25〜30/人/月) | Team Premium ($150/人/月) | Enterprise |
|------|------|-------------|-------------------|--------------------|-----------------------------|--------------------------|------------|
| Claude Code | ❌ | ✅ | ✅ | ✅ | ✅ | ✅（5倍） | ✅ |
| モデル | Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet |
| 利用量 | 制限あり | 標準 | 5倍 | 20倍 | 標準 | 5倍 | カスタム |

## 重要なポイント

### Claude Code を使うには Pro 以上が必要

Free プランでは Claude Code は使えません。最低でも Pro プラン（$20/月）が必要です。

### Max プランは利用量が増える

Max 5x と Max 20x は、Pro の 5倍・20倍の利用量が使えます。Claude Code をヘビーに使う場合は Max プランを検討してください。

### モデルの種類

- **Opus**: 最も高性能。複雑なタスク向き。
- **Sonnet**: バランス型。日常的なタスクに最適。
- **Haiku**: 軽量・高速。シンプルなタスク向き。

### 利用制限（レートリミット）

各プランには利用制限があります。制限に達すると一時的に利用できなくなります。

- **制限の仕組み**: 一定時間内に送信できるメッセージ数やトークン数に上限があります。制限に達すると、リセットされるまで待つ必要があります。
- **Opus モデルは消費が大きい**: Opus は Sonnet に比べてトークン消費が多いため、同じプランでも利用可能回数が少なくなります。用途に応じてモデルを使い分けましょう。
- **制限に達したら**: 画面上に制限到達のメッセージが表示されます。時間が経てば自動的にリセットされます。ヘビーに使う場合は Max プランへのアップグレードを検討してください。

### 会話のクリア（コンテキストの管理）

Claude との会話が長くなると、コンテキストウィンドウ（Claude が一度に参照できる情報量）を圧迫し、応答の質が低下したりトークンを多く消費します。

- **こまめに新しい会話を始める**: 話題が変わったら、新しい会話を開始しましょう。一つの会話に複数のトピックを詰め込まないのがコツです。
- **Claude Code では `/clear` を活用**: Claude Code では `/clear` コマンドでコンテキストをリセットできます。タスクが完了したら都度クリアする習慣をつけましょう。
- **なぜ重要か**: コンテキストが短い方が応答速度が速く、トークン消費も少なく、利用制限にも余裕が生まれます。
