# Step 01: 料金プラン・制限の理解

## 目標

Claude の料金プランごとの違いと、Claude Code の利用条件を理解する。

## プラン比較

| 項目 | Free | Pro ($20/月) | Max 5x ($100/月) | Max 20x ($200/月) | Team ($30/人/月) | Enterprise |
|------|------|-------------|-------------------|--------------------|--------------------|------------|
| Claude Code | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| MCP コネクタ | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| モデル | Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet | Opus/Sonnet |
| 利用量 | 制限あり | 標準 | 5倍 | 20倍 | チーム管理 | カスタム |

## 重要なポイント

### Claude Code を使うには Pro 以上が必要

Free プランでは Claude Code は使えません。最低でも Pro プラン（$20/月）が必要です。

### Max プランは利用量が増える

Max 5x と Max 20x は、Pro の 5倍・20倍の利用量が使えます。Claude Code をヘビーに使う場合は Max プランを検討してください。

### モデルの種類

- **Opus**: 最も高性能。複雑なタスク向き。
- **Sonnet**: バランス型。日常的なタスクに最適。
- **Haiku**: 軽量・高速。シンプルなタスク向き。

Claude Code ではデフォルトで Opus が使われます（Fast モードでは Sonnet）。

### 利用制限（レートリミット）

各プランには利用制限があります。制限に達すると一時的に利用できなくなります。`/fast` モードを活用することで、制限内でより多くのタスクをこなせます（Step 11 で詳しく学びます）。

2. チームメンバーと自分のプランが異なる場合、何が違うか把握しましょう
