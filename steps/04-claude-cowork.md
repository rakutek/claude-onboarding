# Step 04: Claude Cowork の理解と活用

## 目標

Claude Cowork の概念を理解し、Claude Code との違いや使い分けを把握する。非エンジニアも含めたチームでの活用イメージを持つ。

## Claude Cowork とは

Claude Cowork は、Claude Code のエージェント機能を Claude Desktop アプリに統合したものです。ターミナルを使わずに、複雑なマルチステップタスクを自律的に実行できます。

```
Claude Desktop アプリ
├── Chat モード      ← 従来の会話型 AI
└── Cowork モード    ← エージェント型の作業支援
      ├── ローカルファイル読み書き（アップロード不要）
      ├── サブエージェントによる並列処理
      ├── Excel / PowerPoint / 文書の生成
      ├── 長時間タスクの実行（タイムアウトなし）
      └── 定期タスクの自動実行
```

## Claude Code との違い

| | Claude Code | Claude Cowork |
|---|------------|---------------|
| 対象ユーザー | 開発者 | すべてのナレッジワーカー |
| 動作場所 | ターミナル（CLI） | Claude Desktop アプリ |
| 主な用途 | コード生成・編集・実行 | 文書作成・データ整理・リサーチ |
| 操作対象 | コード・ファイル・コマンド | ファイル・Excel・PowerPoint |
| インターフェース | コマンドライン | GUI（チャット形式） |
| 利用イメージ | ペアプログラマー | 同僚にタスクを依頼する感覚 |

## 共通のアーキテクチャ

Claude Code と Cowork は同じエージェントアーキテクチャを共有しています。

```
┌──────────────────────────────────┐
│       Claude のエージェント基盤     │
│                                  │
│  ┌────────────┐  ┌────────────┐ │
│  │ Claude Code │  │  Cowork    │ │
│  │ （CLI）      │  │ （Desktop）│ │
│  └────────────┘  └────────────┘ │
│         │               │       │
│    開発タスク       ナレッジワーク   │
│                                  │
│  共通機能：                       │
│  - ローカルファイルアクセス          │
│  - サブエージェント調整             │
│  - MCP コネクタ                    │
│  - スキル                         │
└──────────────────────────────────┘
```

## できること

| カテゴリ | 具体例 |
|---------|--------|
| 文書作成 | レポート、提案書、議事録のドラフト作成 |
| データ整理 | ダウンロードフォルダの整理、CSV の集計 |
| リサーチ | 複数ファイルを横断した情報収集・要約 |
| スプレッドシート | Excel ファイルの作成・編集・分析 |
| プレゼン | PowerPoint スライドの生成 |
| 定型業務 | 定期レポートの自動生成 |
| 並列処理 | 複数タスクのキューイングと同時実行 |

## セットアップ手順

### 1. Claude Desktop を開く

macOS または Windows（x64）の Claude Desktop アプリを起動します。

### 2. Cowork モードに切り替える

1. アプリ内の **「Cowork」タブ** を選択
2. **「Tasks」モード** に切り替える

### 3. フォルダアクセスを許可する

Claude がアクセスするフォルダを明示的に指定します。指定したフォルダのみ読み書きが可能です。

### 4. タスクを依頼する

自然言語でタスクを説明し、Claude の作業方針を確認してから実行を開始します。

> **注意**: タスク実行中はアプリを開いたままにしておく必要があります。

## 使い方のイメージ

同僚にメッセージを残すような感覚で使えます。

```
あなた → Claude Cowork:
「先週のミーティング議事録（Downloads/meeting-notes.txt）を
 読んで、アクションアイテムを Excel にまとめて」

Claude Cowork:
1. ファイルを読み取る
2. アクションアイテムを抽出
3. 担当者・期限を整理
4. Excel ファイルを生成して保存
```

## セキュリティに関する注意

| 推奨 | 非推奨 |
|------|--------|
| 許可したフォルダのみアクセスさせる | 機密データを含むフォルダを全許可する |
| 作業方針を確認してから実行する | 確認なしで破壊的な操作を許可する |
| 出力結果を必ずレビューする | 規制対象の業務に使う |
| 重要なファイルはバックアップしておく | プロンプトインジェクションのリスクを無視する |
