# Step 06: Claude Code のインストール

## 目標

Claude Code をターミナルにインストールし、正常に動作することを確認する。

## Claude Code とは

Claude Code は、ターミナル上で動作する AI コーディングアシスタントです。ファイルの読み書き、コマンド実行、Web 検索など、開発に必要な操作を自然言語で指示できます。

```
┌─────────────────────────────────┐
│ ターミナル                        │
│                                 │
│ $ claude                        │
│ > ファイルを読んで修正して         │
│                                 │
│ Claude が自動でファイルを読み、    │
│ 編集し、テストを実行する           │
└─────────────────────────────────┘
```

## インストール手順

### 1. インストールコマンドを実行

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

これだけで完了です。Node.js や npm のインストールは不要です。

### 2. 初回ログイン

```bash
claude
```

初回起動時に認証画面が表示されます。ブラウザでログインして認証を完了してください。

## 知っておくべき基本ルール

Claude Code を使い始める前に、以下の点を押さえておきましょう。

### コンテキストの管理

Claude Code との会話には**コンテキストウィンドウ**（記憶容量）の制限があります。1 つのチャットを長く使い続けると、古い内容が圧縮・省略されていきます。

- **1 タスク 1 チャット**を心がける。タスクが完了したら `/exit` で終了し、新しいチャットを始める
- 会話が長くなったら `/compact` で要約して、コンテキストを節約する
- `/clear` で会話履歴をリセットすることもできる

### 使用量の制限

Claude Code には使用量の上限（リミット）があります。プランによって上限が異なります。

- リミットに達すると一時的に利用できなくなる（一定時間後に回復）
- `/cost` で現在のセッションの使用量を確認できる
- リミットを意識して、効率的にプロンプトを書くことが重要

### Plan モードの活用

複雑なタスクに取り組む前に、**Plan モード**を使うことを強く推奨します。

- `Shift + Tab` で Plan モードに切り替えられる
- Plan モードでは、Claude がコードを変更せずに計画だけを立てる
- 計画を確認してから通常モードに戻して実行すると、意図しない変更を防げる

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| `command not found` | ターミナルを再起動してパスを反映 |
| 認証エラー | `claude logout` → `claude` で再ログイン |
| 古いバージョン | `claude update` で更新 |

## やってみよう

1. ターミナルを開く
2. インストールコマンドを実行する
3. `claude` を起動して初回認証を完了する
4. 認証後、何か簡単な質問をしてみる（例：「今日の日付を教えて」）
5. `/exit` で終了する
