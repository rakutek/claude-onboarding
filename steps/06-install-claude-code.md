# Step 06: Claude Code のインストール

## 目標

Claude Code をターミナルにインストールし、正常に動作することを確認する。

## Claude Code とは

Claude Code は、ターミナル上で動作する AI コーディングアシスタントです。ファイルの読み書き、コマンド実行、Web 検索など、開発に必要な操作を自然言語で指示できます。

```
┌─────────────────────────────────┐
│ ターミナル                        │
│                                 │
│ $ claude                        │
│ > ファイルを読んで修正して         │
│                                 │
│ Claude が自動でファイルを読み、    │
│ 編集し、テストを実行する           │
└─────────────────────────────────┘
```

## インストール手順

### 1. インストールコマンドを実行

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

これだけで完了です。Node.js や npm のインストールは不要です。

### 2. 初回ログイン

```bash
claude
```

初回起動時に認証画面が表示されます。ブラウザでログインして認証を完了してください。

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| `command not found` | ターミナルを再起動してパスを反映 |
| 認証エラー | `claude logout` → `claude` で再ログイン |
| 古いバージョン | `claude update` で更新 |

## やってみよう

1. ターミナルを開く
2. インストールコマンドを実行する
3. `claude` を起動して初回認証を完了する
4. 認証後、何か簡単な質問をしてみる（例：「今日の日付を教えて」）
5. `/exit` で終了する
