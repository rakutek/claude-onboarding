# 対話型ステップ進行スキル

チュートリアルを対話形式で進行します。

## 進行手順

1. **進捗確認**: `progress.json` を読み取り、`currentStep` を確認する

2. **ステップファイル読み込み**: `currentStep + 1` に対応する `steps/XX-*.md` を読み込む
   - 例: currentStep が 0 なら `steps/01-pricing-plans.md` を読む
   - currentStep が 12（全完了）の場合は、完了メッセージを表示して終了

3. **目標の提示**: ステップの「目標」セクションをユーザーに伝える

4. **対話形式の解説**: 本文の内容を、一方的に長文を出すのではなく、適度に区切りながら対話形式で説明する
   - 重要なポイントは強調する
   - 表やリストは見やすく整形する
   - ユーザーの理解度を確認しながら進める

5. **課題のガイド**: 「やってみよう」セクションの課題を案内し、ユーザーが実行するのをサポートする
   - コマンドの実行が必要な場合は、実行して結果を見せる
   - 設定変更が必要な場合は、手順を丁寧にガイドする

6. **確認チェック**: 「確認チェック」の各項目を検証する
   - 自動検証可能な項目（コマンド実行で確認できるもの）は自動で確認する
   - 理解度に関する項目は、簡単な質問で確認する

7. **進捗更新**: すべてのチェックをクリアしたら、`progress.json` を更新する
   - `currentStep` を +1 する
   - `completedSteps` に完了したステップ番号を追加する
   - `lastUpdatedAt` を現在の日時に更新する
   - `startedAt` が null の場合は、現在の日時を設定する

8. **次への案内**: 「ステップ XX が完了しました。`/next` で次に進めます。」と案内する

## 出力のトーン

- 丁寧な標準語で、わかりやすく説明する
- 初心者にも伝わるように、専門用語には補足を入れる
- 一度に大量のテキストを出さず、対話のキャッチボールを意識する

## 全ステップ完了時

```
おめでとうございます！すべてのステップが完了しました。

Claude Code の基本概念と環境構築について一通り学習できました。
ここからは実際のプロジェクトで Claude Code を活用してみてください。

/check-setup で最終的な環境状態を確認できます。
```
