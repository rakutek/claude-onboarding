# 環境確認スキル

現在の Claude Code 環境をチェックし、結果を表形式で報告します。

## 手順

1. 以下のコマンドを順に実行して情報を収集してください：

```bash
claude --version
```

```bash
which claude
```

```bash
claude mcp list 2>/dev/null || echo "MCP未設定"
```

```bash
claude config list 2>/dev/null || echo "設定取得不可"
```

2. `progress.json` を読み取り、現在の進捗を取得してください。

3. 結果を以下の表形式で報告してください：

```
## 環境チェック結果

| 項目 | 状態 | 詳細 |
|------|------|------|
| Claude Code | ✅ or ❌ | バージョン番号 or 未インストール |
| MCP サーバー | ✅ or ❌ | 接続中のサーバー一覧 or 未設定 |
| 言語設定 | ✅ or ⚠️ | 設定済みの言語 or 未設定 |
| チュートリアル進捗 | Step X/12 | 完了済みステップ数 |
```

4. 未完了の項目がある場合は、対応するステップ番号を案内してください。

## 出力のトーン

丁寧な標準語で、簡潔に報告してください。問題がある項目は、解決方法のヒントも添えてください。
