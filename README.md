# Claude Code オンボーディングチュートリアル

Claude Code の基本概念と環境構築を **10 ステップ** で学ぶ対話型チュートリアルです。

## はじめに

このチュートリアルでは、Claude Code を使い始めるために必要な知識とセットアップを一通り体験できます。
Claude Code 自身がガイド役となり、対話形式でステップを進めていきます。

## 前提条件

- macOS / Linux 環境（Windows は WSL2 を推奨）
- Node.js v18 以上
- ターミナルの基本操作ができること
- Anthropic のアカウント（Pro プラン以上を推奨）

## 始め方

### 1. リポジトリをクローン

```bash
git clone <このリポジトリの URL>
cd claude-onboarding
```

### 2. Claude Code を起動

```bash
claude
```

### 3. チュートリアルを開始

Claude Code が起動すると、ウェルカムメッセージが表示されます。
`/next` と入力して最初のステップに進みましょう。

## ステップ一覧

チュートリアルは **座学 → 環境構築 → 体験 → 応用** の 4 フェーズで構成されています。

| # | 内容 | フェーズ |
|---|------|---------|
| 01 | 料金プラン・制限の理解 | 座学 |
| 02 | MCP（コネクタ）の設定 | 座学 |
| 03 | Claude Code のインストール | 環境構築 |
| 04 | 言語設定（/config） | 環境構築 |
| 05 | CLAUDE.md の理解 | 体験 |
| 06 | Chrome DevTools MCP の追加 | 体験 |
| 07 | Skills の概念理解 | 体験 |
| 08 | Artifacts の概念理解 | 体験 |
| 09 | Agent Team の理解 | 応用 |
| 10 | Claude in Chrome の導入と活用 | 体験 |

## 使えるコマンド

| コマンド | 説明 |
|---------|------|
| `/next` | 次のステップに進む |
| `/check-setup` | 環境の状態を確認する |
| `/setup-mcp` | MCP コネクタの設定をガイドする |

## 進捗について

- 進捗は `progress.json` に自動保存されます
- 途中で中断しても、次回起動時に続きから再開できます
- 各ステップは `steps/` ディレクトリ内のファイルとして独立しており、個別に参照することもできます

## 注意事項

- このチュートリアルは **概念理解と環境構築** にフォーカスしています。実践的なコード生成は対象外です
- 各ステップは独立して参照可能ですが、順番に進めることを推奨します
